Church Synth - Preset Pack 11: Synthwave
50 presets for synthwave / retrowave / outrun, tagged, each with "How it's built"
notes. Needs Church Synth v0.2.1 or later.

INSTALL
Copy this whole folder ("Pack 11 - Synthwave") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then press Rescan in the preset browser. Every preset carries the "Synthwave" tag.

THE INGREDIENTS (the notes point them out)
  sequenced sixteenth basses, octave jumps, gallops and triplets
  arpeggios with dotted-eighth echoes
  vintage chorus everywhere, big halls, shimmer
  tape wobble and hiss for the VHS feel
  side-chain style pumping (Function "Duck" on the amp)
  supersaw unison, sync leads, FM electric pianos and bells
Sequenced sounds follow the host tempo: hold a note (basses) or a chord (arps).

MACROS
  M1 Brightness    M2 Space (reverb send)
  M3 a character control (Echo, Punch, Resonance, Width, Pump, Vowel...)
  M4 Decay / Attack / Release / Gate
