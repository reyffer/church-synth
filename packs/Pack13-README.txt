Church Synth - Preset Pack 13: Famous Sounds
50 timbres inspired by famous synth sounds from records and films, with "nod"
names, tagged, each with "How it's built" notes. Needs Church Synth v0.2.1 or later.

ABOUT THESE SOUNDS
These are our own recipes, built from scratch to get close to the character of each
sound. No factory patch data was copied, and no preset plays a song's riff or
melody: arps and sequences use generic patterns. Learning to hear what makes a
famous sound tick (the octave layer, the resonance, the chorus, the glide) is the
point of the notes.

INSTALL
Copy this whole folder ("Pack 13 - Famous Sounds") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then press Rescan in the preset browser. Every preset carries the "Famous" tag,
plus a decade tag (70s, 80s, 90s) where it fits.

MACROS
  M1 Brightness    M2 Space (reverb send)
  M3 a character control    M4 Decay / Attack / Release / Gate
