Church Synth - Preset Pack 5: Brass
20 presets, tagged, each with "How it's built" notes (shown under the browser).
Needs Church Synth v0.2.1 or later.

INSTALL
Copy this whole folder ("Pack 5 - Brass") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then press Rescan in the preset browser.

ABOUT THESE SOUNDS
Synth brass built the way brass behaves: the harder you play, the brighter it gets;
each note scoops up into pitch; a little breath; several slightly out-of-tune
players. Great for stabs, swells and pads. The horns are synth horns, not samples:
they shine in a mix, less so fully exposed.

MACROS
  M1 Brightness    M2 Space (reverb send)
  M3 a character control (Bite, Swell, Scoop, Fall, Blat, Drive, Octave...)
  M4 Attack / Release / Length
Solo Trumpet, Muted Trumpet and Flugelhorn are mono and legato (overlap notes to
slide); aftertouch adds vibrato.
