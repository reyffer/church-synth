Church Synth - Preset Pack 8: Ladder
20 presets in the style of the classic three-oscillator mono synth with the ladder
filter (Moog-style), plus a few ladder polysynths and a bass-pedal sound. Tagged,
each with "How it's built" notes. Needs Church Synth v0.2.1 or later.

INSTALL
Copy this whole folder ("Pack 8 - Ladder") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then press Rescan in the preset browser. Every preset carries the "Ladder" tag.

HOW THEY'RE BUILT
  THREE oscillators (Osc 3 often an octave down) + noise
  -> the mixer pushed into the filter (filter Drive = the original's overdriven mixer)
  -> the 24 dB ladder lowpass
  -> a filter contour (Env 2) and a loudness contour (Env Amp); the release usually
     equals the decay, like the original's decay switch
  Mono, with glide. The mod wheel adds vibrato on most leads.

MACROS
  M1 Brightness    M2 Space (reverb send)
  M3 a character control (Contour, Resonance, Drive, Growl, Breath, Trill Speed...)
  M4 Decay / Release / Gate

WHAT'S IN IT
Bass: Classic Ladder Bass, Round Soul Bass, Pedal Bass, Funk Pluck Bass,
  Overdriven Bass, Glide Bass, Squelch Bass, Ladder Sequence 16ths
Leads: Classic Ladder Lead, Portamento Lead, Octave Saw Lead, Flute Lead,
  Funky Square Lead, Trill Lead, Screaming Lead, Soft Mono Lead
Poly: Ladder Poly Brass, Ladder Poly Pad, Ensemble Poly Strings, Ladder Pluck Keys

Pedal Bass is made for holding the root under worship; it needs a PA with subs.
