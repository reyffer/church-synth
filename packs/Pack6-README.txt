Church Synth - Preset Pack 6: Chorus Poly
20 presets in the style of the classic 80s one-oscillator chorus polysynth
(Juno-style), tagged, each with "How it's built" notes. Needs Church Synth v0.2.1+.

INSTALL
Copy this whole folder ("Pack 6 - Chorus Poly") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then press Rescan in the preset browser. Every preset carries the "Chorus Poly" tag;
if you renamed that tag (to "Juno", say), Rescan applies your rename to these too.

HOW THEY'RE BUILT (the same recipe every time, so the pack teaches the synth)
  one oscillator per voice: saw and/or pulse (with PWM from the LFO)
  + a square sub an octave down + a little noise
  -> highpass (flat, thin or thinner) -> smooth 4-pole lowpass (OTA model)
  -> ONE envelope for filter and amp (or a simple gate for the amp)
  -> the Vintage Chorus, I, II or I + II, which is half the sound.
One LFO with a delay (fade-in) for PWM, filter movement or vibrato.
Velocity is light on purpose: the original had none.

MACROS
  M1 Brightness    M2 Space (reverb send)
  M3 a character control (PWM Speed, Motion, Sub, Bite, Echo, Resonance...)
  M4 Attack / Decay / Release

WHAT'S IN IT
Pads and strings: PWM Strings, Saw Strings, Dream Pad, Night Drive Pad,
  Breathing Pad, Sweep Pad
Keys, stabs, plucks: Chorus Brass, Poly Stab, Chorus Keys, Pulse Organ, Poly Pluck,
  Resonant Bell, Chord Memory Stab
Bass: Square Sub Bass, Saw Bass Punch, Rubber Bass, Arp Bass 16ths
Leads and arps: Chorus Lead, Resonant Whistle, Chorus Arp
