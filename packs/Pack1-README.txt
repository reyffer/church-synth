Church Synth - Preset Pack 1: Keys, Strings and Synths
50 presets. Needs the Church Synth build from 5 Nov 2026 or later.

INSTALL
Copy this whole folder ("Pack 1 - Keys, Strings and Synths") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
Then open the preset browser: the sounds are in the User bank and in their
categories (Keys, Pad, Strings/Brass, Pluck, Lead, Bass, Sequence).
If the plugin was already open, close and reopen its window so the browser
picks them up.

MACROS (same idea on every preset)
  M1 Brightness / Tone / Bark    M2 Space (reverb send)
  M3 a character control (Tremolo, Hammer, Vibrato, Echo...)
  M4 Decay / Attack / Release / Gate

WHAT'S IN IT
Electric pianos (Keys)
  Tine Piano, Suitcase Keys, Reed Piano, Eighties Tines, Dreamy EP, Electric Grand
Felt pianos and other keys (Keys)
  Felt Piano, Felt Lullaby, Felt Upright, Keys and Pad
Strings (Strings/Brass)
  Chamber Strings, Ensemble Strings, Slow Strings Swell, Pizzicato Strings,
  Tremolo Strings, Silk Strings
Bells (Pluck, and one Pad)
  Tubular Bells, Music Box, Glockenspiel, Crystal Bells, Celesta, Bells into Pad
Evolving pads (Pad)
  Harmonic Drift, Breathing Vowels, Glass Tides, Slow Bloom, Spectral Motion, Aurora
Polysynth pads (Pad)
  Poly Brass Pad, Vintage Poly Pad, Wide Saw Pad, Analog Sweep Pad, Expressive Poly
Classic 80s chorus polysynth ("Chorus Poly": one oscillator + sub + chorus)
  Chorus Poly Pad, Chorus Poly Strings, Chorus Poly Brass, Chorus Poly Keys,
  Chorus Poly Bass, Chorus Poly Arp
Ladder-filter mono leads (Lead) - mod wheel = vibrato
  Ladder Lead, Fat Mono Lead, Soft Ladder Lead, Resonant Sweep Lead, Fifth Ladder Lead
Pulsing bass sequences (Bass) - hold one note; they follow the host tempo
  Pulse Bass 8ths, Octave Pulse Bass, Rolling Bass 16ths, Gated Sub Pulse,
  Dark Pulse Bass, Synthwave Bass

All presets are level-matched with the factory set (about -4 dBFS peak for a
four-note chord, -7 dBFS for mono sounds).
