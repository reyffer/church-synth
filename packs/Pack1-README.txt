Church Synth - Preset Pack 1: Keys, Strings and Synths
75 presets, tagged, each with "How it's built" notes (shown under the browser).
Needs Church Synth v0.2 or later: the organs use the Rotary effect.

INSTALL
Copy this whole folder ("Pack 1 - Keys, Strings and Synths") into:
  Mac:     Documents/Church Synth/Presets
  Windows: Documents\Church Synth\Presets
If you installed an earlier version of this pack, replace that folder with this one
(same names, so your tag edits and favourites are kept).
Then press Rescan in the preset browser. The sounds are in the User bank, in their
categories, and under their tags.

TAGS (rename or delete them in the browser: right-click a tag)
  Chorus Poly     the 80s one-oscillator chorus polysynth (Juno-style)
  Vintage Poly    the late-70s five-voice classic (Prophet-style)
  Grand Poly      the 80s 8-voice flagship (Jupiter-style)
  Ladder          mono synths with a ladder filter (Moog-style)
  Tonewheel       drawbar organ with a rotary speaker (Hammond / Leslie-style)
  String Machine  70s string ensemble (Solina-style)
  Pipe Organ, Organ, Piano, Electric Piano, Felt, FM, Synth Keys, Strings, Brass,
  Choir, Bells, Mallet, Pad, Evolving, Ambient, Swell, Cinematic, Polysynth, Lead,
  Mono, Bass, Sub, Pulsing, Arp, Short, Lo-Fi, Worship

MACROS (same idea on every preset)
  M1 Brightness / Tone / Bark    M2 Space (reverb send)
  M3 a character control (Tremolo, Hammer, Vibrato, Echo... on the organs: Rotary Fast)
  M4 Decay / Attack / Release / Gate / Drive
On the organs the mod wheel also switches the rotary to fast.

WHAT'S IN IT
Electric pianos: Tine Piano, Suitcase Keys, Reed Piano, Eighties Tines, Dreamy EP, Electric Grand
Felt pianos and keys: Felt Piano, Felt Lullaby, Felt Upright, Keys and Pad
Organs: Gospel Drawbars, Full Drawbars, Jazz Organ, Chapel Organ, Organ Swell Pad,
  Full Pipe Organ, Soft Flute Stop, Chorus Poly Organ
Strings: Chamber, Ensemble, Slow Strings Swell, Pizzicato, Tremolo, Silk, Expressive
  (mod wheel = bow), Octave, Low, Spiccato, Strings and Choir, Poly Strings,
  Chorus Poly Strings, Vintage Poly Strings
Bells: Tubular Bells, Music Box, Glockenspiel, Crystal Bells, Celesta, Bells into Pad, Grand Poly Bells
Evolving pads: Harmonic Drift, Breathing Vowels, Glass Tides, Slow Bloom, Spectral Motion, Aurora
Polysynths: Poly Brass Pad, Vintage Poly Pad / Brass / Keys / Sync, Wide Saw Pad,
  Analog Sweep Pad, Expressive Poly, Grand Poly Pad / Brass / Sweep / Arp,
  Chorus Poly Pad / Brass / Keys / Bass / Arp / Sweep / Soft Pad
Ladder leads (mod wheel = vibrato): Ladder Lead, Fat Mono Lead, Soft Ladder Lead,
  Resonant Sweep Lead, Fifth Ladder Lead
Pulsing bass sequences (hold one note; they follow the tempo): Pulse Bass 8ths,
  Octave Pulse Bass, Rolling Bass 16ths, Gated Sub Pulse, Dark Pulse Bass, Synthwave Bass

All presets are level-matched with the factory set (about -4 dBFS peak for a
four-note chord, -7 dBFS for mono sounds).
